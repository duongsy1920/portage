# Kiến thức riêng của Portage

Thư mục này **rỗng có chủ ý** cho tới khi một task thật sinh ra một điều đáng giữ mà
không có chỗ nào trong repo Portage đã ghi. Hầu hết kiến thức về Portage đã ở đúng chỗ
của nó: `CLAUDE.md`, `docs/SETUP.md` §9, `docs/DDD.md`. **Không chép sang đây.**

Một file ở đây được sinh khi: routine `analyze` gợi ý ("điều này chưa ghi ở đâu") và
người chốt. Tên file = một câu khẳng định, ví dụ `cau-hinh-khac-value-object.md`.
